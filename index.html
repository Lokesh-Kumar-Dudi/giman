GiMan gid

Manage multiple Git identities via SSH — use personal and work GitHub accounts on the same machine.

View on GitHub Docs (Markdown)

Install

npm install -g giman

Quick start

gid init

Then map directories to identities:

gid dir add ~/dev/personal --identity personal
gid dir add ~/dev/work --identity work

Commands

gid init · gid status · gid apply
gid identity list|add|edit|remove|show
gid dir add <path> --identity <id> · gid dir remove|list
